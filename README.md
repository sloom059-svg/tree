# شجرة عائلة الجارالله

الكود الأساسي للموقع: **https://aljarallah.vercel.app/**

هذا المستودع هو مرجع ملفات المشروع ومتابعة التعديلات. نقل الكود إلى GitHub لا ينقل بيانات العائلة؛ تبقى الأسماء والطلبات وحساب المسؤول في قاعدة Supabase الحالية.

## الملفات

| الملف | الوظيفة |
| --- | --- |
| `index.html` | صفحات الموقع والنماذج والقائمة الجانبية |
| `app.js` | الاتصال بقاعدة Supabase والشجرة والطلبات وإدارة الأفراد |
| `tree.css` | تنسيقات الشجرة والنوافذ وصفحة تأكيد الطلب |
| `workspace.css` | الواجهة المصغرة والقائمة ومساحة الشجرة |
| `workspace.js` | السحب والتقريب والوصلات المنحنية وعدّاد الطلبات |
| `contributions.js` و`contributions.css` | طلبات مرتبة ومراجعة وتعديل الطلب ونموذج مساهمة من ثلاث خطوات |
| `request-utils.js` | التحقق من الأسماء والبحث في النسب والتاريخ الميلادي |
| `supabase/review_family_request.sql` | مصدر دالة المراجعة الذرية المطبقة على القاعدة الحالية |

لا توجد عملية بناء أو مكتبات مطلوب تثبيتها لتشغيل الموقع:

```sh
python3 -m http.server 8000
```

## الحفاظ على البيانات

- المشروع عربي RTL، للرجال فقط، بعلاقات أب وابن وأخ.
- لا تعِد إنشاء مشروع Vercel أو قاعدة Supabase عند متابعة العمل.
- احتفظ بالجداول والدوال والسياسات الحالية. افحصها قبل أي تعديل بنيوي.
- عدّاد طلبات الإضافة يعرض الطلبات `pending` للمسؤول فقط، ويتحدث كل 20 ثانية أثناء ظهور الصفحة، وعند الرجوع إليها، وبعد المراجعة.
- السحب يحرك مساحة الشجرة. التقريب يعمل بإصبعين وبعجلة الماوس وبالأزرار. زر الاحتواء يعيد ضبط الشجرة كاملة داخل الشاشة.
- للمستخدم الذي يعتمد لوحة المفاتيح: ركز مساحة الشجرة ثم استخدم الأسهم للتحريك، `+` و`-` للتقريب، و`0` للاحتواء.
- الحذف الحالي قابل للاسترجاع من سلة المحذوفات. ترقية الأبناء تغير ارتباطاتهم ولا تعكسها عملية الاسترجاع تلقائيًا.
- الملفات لا تحتوي نسخة احتياطية من أسماء العائلة أو طلباتها أو حساباتها.

يمكن حفظ تعديلات الطلب دون إضافة أسماء، أو اعتماد الأسماء والأب المعدّل في عملية واحدة. لا يُغيّر ذلك تاريخ الطلب الأصلي أو رمزه الخاص.

راجع `ALJARALLAH_HANDOFF.md` لتفاصيل الدوال والقرارات السابقة.

## التحقق

```sh
node --check app.js
node --check workspace.js
node --test tests/*.test.cjs
```

اختبارات التفاعل تستخدم بيانات وهمية وبيئة DOM مبسطة، ولا ترسل طلبات إلى قاعدة البيانات.
